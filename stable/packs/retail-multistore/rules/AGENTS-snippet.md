# 贴进你项目 AGENTS.md（或 CLAUDE.md）的几行

把下面这段原样贴进你项目根目录的 `AGENTS.md`。这是让模式每轮到场的唯一机制——放在 `.agents/patterns/` 里不贴指针，harness 不会自己去读。

```markdown
## 多门店零售 · 设计模式（retail-multistore 包）

设计收件办理、岗位待办、名称整理，或要把老板说的规则落进系统之前，先读 `.agents/patterns/retail-multistore/README.md`，挑出要用的模式，逐段并进六段设计稿。
模式里的〔待裁〕只认使用者原话：抄原话、说话人、日期；没有就写「待裁」，不替他定。
老板随口说的规则，先按 `.agents/patterns/retail-multistore/caliber-inbox.md` 分四类记下，不当场改参数、不当场改代码。
```

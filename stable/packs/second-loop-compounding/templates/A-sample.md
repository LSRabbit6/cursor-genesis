> 性质：观测件。按 <框架文件> 的 A 模板做的第 <n> 个样本，一页够。目的不是把这件事讲厚，是拿一件刚干完的真事去试框：四条线各能提炼出什么、哪格是空的、探针有没有读数。
> 顺序：这件事已干完（<干完的证据：提交号 / 上线 / 交付 / 对方已收>），所以现在复盘合规矩。
> 边界：<只有长线关系才写：取了哪几个里程碑当「这件事」、出处在哪；其余删掉这一行>

## 2 按四线各提炼出什么

| 线 | 提炼出来的 | 状态 |
|---|---|---|
| **认知线** | <判断 / 方法 / SOP / 案例，给自己下一次上场用的；编号 ① ② …；没有写「无」> | <已进判断层 / 已登提炼队列 / 未登，候选> |
| **资产线** | <工具 / 作品 / 交付物 / 对外材料，别人看、别人用的；没有写「无」，不硬凑> | <已登资产清单 / 未登 / 过了红队没> |
| **元运维线** | <工作台自身的架构判断、断点读数、修复 + 回归测试、假声明清单> | <已提交（提交号）/ 未提交> |
| **人际线** | <对一个人的理解（含对用户本人的理解），四层分开：他说过的 / 我理解的 / AI 推导的 / 他反馈的；我学到的 / 我分享的 / 共同经历> | <已回写那人的线文件第几节 / 只落在本样本> |

## 3 用什么方式提炼的（对照框架「三定义」的提炼方式行）

- 认知线：<走通 / 哪一步没走——如「进了项目缓存、没进提炼队列」>
- 资产线：<走通 / 无>
- 元运维线：<观测件 + 拍板行 + 回归测试，走通没>
- 人际线：<会面复盘 / 会话标签 / 四层回写，有没有现成的回写口>
- **缺的方式标出来**：<哪条线今天没有提炼口，只能先放本样本>

|---|---|---|---|---|---|
| <积累> | <场景> | <人 / AI / 机器 / 另一个 agent> | <不重推 / 不用读原始长报告 / 读数可信 …> | <回写到哪个文件哪一节> | <已上场 N 次 / 待下次（写预计时刻）> |

## 5 放哪（归位）
